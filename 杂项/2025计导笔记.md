## 原码、反码、补码
`本质是如何表示负数以方便加减的问题`
原码：第一位01表正负，后所有位直接表示数绝对值大小
反码：第一位01表正负，后所有位在原码基础上逐位取反
补码：第一位01表正负，负数在反码基础上加一
补码利用‘溢出’将
BCD码：四位2进制数表示一位十进制数

一种类scheme的表达式
akeman递归函数
```haskell
 ack 0 n = n + 1
 ack m 0 = ack (m - 1) 1
 ack m n = ack (m - 1) (ack m (n - 1))
```
	m 递减时， _n_ 的增加没有上界，而且增加的幅度较大。

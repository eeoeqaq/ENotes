```c
for (i = 0; i < n; i += 2) { 
	acc1 = (acc1 + data[i]) + data[i+1]; //can improve

for (i = 0; i < n; i += 2) { 
	acc0 = acc0 + data[i]; // 这两条指令互不依赖！ 
	acc1 = acc1 + data[i+1]; // 可以被 CPU 同时并行处理 
} 
acc = acc0 + acc1;
```

## 妨碍优化的因素
### 过程调用
类似于黑箱，编译器不敢激进优化。故我们需要内联函数
### 内存别名
考虑这种情况让编译器不敢优化程序性能。故我们用局部变量告诉编译器可以优化
from
```c
/* Sum rows is of n X n matrix a and store in vector b */ 
void sum_rows1(double *a, double *b, long n) { 
	long i, j; 
	for (i = 0; i < n; i++) { 
		b[i] = 0; 
		for (j = 0; j < n; j++) b[i] += a[i*n + j];
	}
}
```
to
```c
/* Sum rows is of n X n matrix a and store in vector b */ 
void sum_rows2(double *a, double *b, long n) { 
	long i, j;
	for (i = 0; i < n; i++) { 
		double val = 0; 
		for (j = 0; j < n; j++) val += a[i*n + j]; 
		b[i] = val; 
	} 
}
```

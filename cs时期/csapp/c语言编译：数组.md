## 数组
- 嵌套数组 二维数组 取一次内存地址
- 多级数组  数组指针的数组 取两次内存地址

## 结构体
连续内存储存，声明顺序排列，首位置+偏移量取值，存在到编译器为止

对齐：需要k字节存储的类型地址必须是k的倍数（x8664上建议满足）
整体结构大小必须是最大的k的倍数  `为节省空间可考虑把大型数据放前面`

## 联合体
最大元素分配，一次只使用一个字段，
```c
typedef union {
	unsigned u;
	float f;
} x 
unsigned fToU(float f) {
	x tar;
	x.f = f;
	return x.u;
}
```

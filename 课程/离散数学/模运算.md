###### 除法
- 需要一个模运算的乘法逆元b，使得 ab 模 m == 1 此语境下除该数等于乘该数的乘法逆元
- 并非所有数都有乘法逆元。a模m有唯一乘法逆元当且仅当a与m互质
	- 证明方法：单射 + 集合大小 -> 满射
- 如何求逆元？
	- 欧几里得算法，计算gcd(a,m)过程中得到gcd(a,m) = k1a + k2m；k1即为所求逆元

###### 中国剩余定理
- 两两互质的一组m1, m2, m3 ... mn; 在这些模下的n个同余方程，在（m1m2m3...mn）下有唯一解
###### 费马小定理
- 对质数q取模下的幂运算有周期性，且周期为q-1
- 和乘法逆元证法类似

###### 常见应用之RSA
- 安全性来源：大整数分解困难——公开 n = pq，但由 n 反推 p、q 目前没有多项式时间算法
- 密钥生成
	- 随机取两个大质数 p、q（n 实际在 2048 位以上），算出 n = pq 与 φ(n) = (p-1)(q-1)
	- 取公钥指数 e：1 < e < φ(n) 且 gcd(e, φ(n)) = 1（常用 65537，二进制中只有两个 1，快速幂快）
	- 求私钥指数 d：e 在模 φ(n) 下的乘法逆元（即上文用扩展欧几里得算法求的那个 k1）
	- 公钥 (n, e) 公开，私钥 (n, d) 保密；p、q、φ(n) 生成后销毁，泄露任意一个都等价于泄露私钥
- 加密与解密
	- 加密：c = m^e mod n（要求消息 0 ≤ m < n）
	- 解密：m = c^d mod n
	- 两个方向是同一个运算（模幂），用快速幂（平方—乘）把 O(e) 次乘法降到 O(log e)
- 正确性证明（解密为什么能还原）
	- d 的取法保证 ed ≡ 1 (mod φ(n))，即 ed = 1 + k(p-1)(q-1)
	- 由费马小定理：m^(p-1) ≡ 1 (mod p) 且 m^(q-1) ≡ 1 (mod q)
	- 于是 c^d = m^ed = m · (m^(p-1))^(k(q-1)) ≡ m (mod p)，对 q 同理
	- 由中国剩余定理：模 p、模 q 都同余于 m，故 c^d ≡ m (mod n)
	- 这里对 p、q 分别用费马小定理（而不是对 n 用欧拉定理），就绕开了 gcd(m, n) = 1 的前提：m 是 p 的倍数时两边模 p 同为 0，结论照样成立
- 小数字例子（只看流程，实际参数远大于此）
	- p = 3，q = 11 → n = 33，φ(n) = 20
	- 取 e = 3，则 d = 7（3 × 7 = 21 ≡ 1 mod 20）
	- 加密 m = 5：c = 5^3 mod 33 = 125 mod 33 = 26
	- 解密 c = 26：26^7 mod 33 = 5 ✓
- 数字签名（同一套密钥，方向反过来用）
	- 签名 s = H(m)^d mod n（用私钥）；验证只需检查 s^e mod n 是否等于 H(m)（用公钥）
	- 先做哈希：把任意长消息压成不超过 n 的定长摘要，同时避免同一消息的签名被整体搬运到别处

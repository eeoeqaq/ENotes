## assymmetric key cryptography

### api
- keygen() ->(public key, private key)

- encrypt(plaintext, public key) ->ciphertext
- decrypt(ciphertext,private key)-> plaintext

- sign(message, privkey) -> signature
- verify(message, signature, pubkey) ->boolean

analogy: give others a box and a open lock, who put sth in the box, close the lock(can't be opened except myself), then give the box back to me.

[^1]: key derivation function

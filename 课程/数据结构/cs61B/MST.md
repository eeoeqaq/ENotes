grim's algorithm
once a edge, repeat r-1 times.
find a set of nodes that is unlinked with the rest nodes
add the shortest edge

kruskal's algorithm
list all the edge from shortest to longest
add a shortest list if won't form a loop (by disjoint set)
totally add r-1 edges

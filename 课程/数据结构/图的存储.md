邻接矩阵，邻接表，逆邻接表
十字链表
`这个数据结构的字段配置很有意思`
```cpp
struct node {
	T val;
	edgeInfo* firstIn;
	edgeInfo* firstOut;
}

struct edgeInfo {
	node* from;  //若用顺序表存储node信息，也可记录node下标
	node* to;
	edgeInfo* nextOut;   //next out of from
	edgeInfo* nextIn;   //next in of to
}
```
`也可以用来存储稀疏矩阵`
邻接多重表
`和上一个类似的字段配置，但用来给无向图存储压缩空间`
```cpp
struct node {
	T val;
	edgeInfo* firstEdge;
}

struct edgeInfo {
	node* n0;  //若用顺序表存储node信息，也可记录node下标
	node* n1;
	edgeInfo* nextEgdeOfN0;   
	edgeInfo* nextEgdeOfN1;   
}
```

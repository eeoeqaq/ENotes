class Light:
    `def __init__(self, on):`
        `self.on = on`

    def __bool__(self):
        return self.on

假设我们写：
`lamp = Light(True)`
Python 实际上在内部做了：
`Light.__init__(lamp, True)`

当你写:
`if lamp:     ...`
Python 实际上会做：
`lamp.__bool__()`

# 3 类成员
- **public（公有）**：对所有作用域可见。
    - 类外可通过对象/指针/引用访问。
    - 派生类中可直接访问。
- **protected（保护）**：对类外不可见，但对派生类可见。
    - 类外不能直接访问。
    - 派生类成员函数中可直接访问。
- **private（私有）**：仅在本类内部可见。
    - 类外不能访问。
    - 派生类也不能直接访问（只能通过本类的公有/保护成员间接操作）。



# 4 标准的类，和由其产生的一般的语法规则
```cpp
class{
	int a;
	public:
	void write();
	int get() const;
};
```
由此：
	常对象只能调用常成员函数；
	派生类的对象和成员函数都无法访问基类的私有成员（为什么基类要有公有函数）

# 6 复制构造函数，移动构造函数
```cpp
T(T&& other);          // 移动构造
T& operator=(T&& other); // 移动赋值

struct Buffer {
    Buffer(Buffer&& o) noexcept
      : ptr(o.ptr), sz(o.sz) {
        o.ptr = nullptr; o.sz = 0;
    }
    Buffer& operator=(Buffer&& o) noexcept {
        if (this != &o) {
            delete[] ptr;
            ptr = o.ptr; sz = o.sz;
            o.ptr = nullptr; o.sz = 0;
        }
        return *this;
    }
    // 拷贝构造/赋值也应定义（或 =default / =delete）
};
```
- **noexcept 很重要**：标准库容器（如 `std::vector`）在扩容搬迁元素时，若移动构造/赋值是 `noexcept`，会优先用移动；否则可能退回拷贝或改变强异常安全策略。

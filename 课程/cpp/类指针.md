
```cpp
class A{
	static int a;//静态成员变量
	static int b(int i);//静态成员函数
	int c;//
	int d(int i);//
};
int A::a=100;

```
# 1 真的是一个成员变量？
```cpp
int* p = &A::a; 
```
普通变量指针

# 2 静态成员函数？？
```cpp
int (*pf)(int) = &A::b;
```
普通函数指针

# 3 动态变量？？？
	__类型 类名::*__
```cpp
int A::* px= &A::c;
```
并非地址，**更像“在对象里的成员位置/偏移描述”**，如何用？
```cpp
A examp{100};
cout<<examp.*px;//100
A* pa=&examp;
cout<<pa->*px;//100
```
# 4 “动态函数”
依旧类似于“相对位置”。使用例：
```cpp
int (A::*pf2)(int)=&A::d;
int bf=(examp.*pf2)(1000);
int bf=(pa->*pf2)(1000);
```
`
3、4显然有一些共同点：相对位置，因此统称为：成员指针。
